# 验证范围

不要将模拟数据解码成功等同于相机实时流已经完成端到端验证。

| 检查 | 验证方式 | 结论范围 |
| --- | --- | --- |
| 素材目录、Range 读取 | 开发期间连接真实 X5 | 已观察到多日素材与原素材／LRV；发现并定位过 HTTP 长连接响应残留问题 |
| 录像控制 | 真实相机命令交互 | 已观察到命令响应；不代表覆盖所有模式及固件 |
| 实时流解析与解码 | 本地 TCP 模拟协议，生成 H.264 后解码 JPEG | 校验协议拆包和解码链路；真实实时流的长期稳定性未完成验证 |
| HTTP 读取修复 | 模拟响应残留、截断、断线和错误 Range | 校验连接隔离、重试及拒绝错误数据 |
| 缓存 | 本地 HTTP 模拟数据 | 校验分块、随机访问及缓存行为 |
| 大文件和导出式读取 | 合成超过 4 GiB 的文件、随机 seek、顺序哈希比对 | 验证偏移与数据一致性，不代表 Studio 实际导出已成功 |
| NFS | 本机 macOS 原生挂载模拟数据源 | 校验读取、EOF 和只读行为 |
| 安全断开 | 模拟卸载繁忙后重试，实际本机挂载 | 校验繁忙时保留服务及后续卸载 |
| 应用打包 | Swift 编译、PyInstaller、签名验证、后端 self-test | 校验打包产物及所需解码库可用 |

0.4.1 修复后的真实 X5 + Insta360 Studio 持续预览与导出测试仍待完成。先前版本曾出现预览卡顿、导出提示素材被删除的情况。不能据目前测试承诺与 USB 有线访问相同的体验。

当前验证硬件为 Apple Silicon Mac；开发期间使用过的相机固件为 `A3_1.13.21.623_build1`。不同系统、固件及拍摄模式需要额外验证。
